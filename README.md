# Pearl Catch (Fabric, Minecraft 26.2)

Client-side mod. Keybinds (rebind in Options > Controls > Pearl Catch):

| Key | Action |
|-----|--------|
| G   | Throw ender pearl, wait the delay, throw wind charge |
| ]   | Increase delay by 1 tick (shown in chat) |
| [   | Decrease delay by 1 tick (shown in chat, 0 = same tick) |

Throws go where you're looking. Needs an ender pearl and a wind charge anywhere in your inventory.

## Getting the jar with GitHub
Upload everything (including the hidden `.github` folder), open the **Actions** tab, wait for the
"Build jar" run to go green, and download **pearlcatch-jar** from Artifacts. Use `pearlcatch-1.0.0.jar`.

## Versions
Minecraft 26.2, Fabric Loader 0.19.3+, Fabric API 0.152.1+26.2, Loom 1.17, Gradle 9.5.1, Java 25.
